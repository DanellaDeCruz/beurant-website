# Beurant website

Portfolio site for **Beurant**, an interior & exhibition design studio in Wattala (Greater Colombo), Sri Lanka, founded 2018 by Bevan David. Warm, dark, minimal, photography-led. Goal: read as a professional studio, not a personal blog.

## Session protocol (do this every session)

- **Start:** read `HANDOFF.md` before doing anything else — it holds current state, open questions and next steps.
- **End:** before finishing a session (or when the user wraps up), update `HANDOFF.md`: add a dated entry with what changed, current state (incl. uncommitted work), open questions for the user, and next steps. Trim entries that are no longer relevant.
- **Also update this file** whenever architecture, conventions, commands or design rules change. Keep it a description of how the project works *now*, not a history — history goes in `HANDOFF.md`.

## Stack

- Next.js 16 (App Router, Turbopack) with `output: "export"` — a fully **static** site. No server: no API routes, no server actions, `images.unoptimized: true`.
- React 19, Tailwind CSS 4 (CSS-first config in `src/app/globals.css`), framer-motion (only for crossfading slideshows).
- TypeScript runs side by side: `typescript` is aliased to `@typescript/typescript6` (typescript-eslint doesn't support TS 7 yet); `@typescript/native` is TS 7 and provides `npx tsc`. Drop the alias once typescript-eslint supports TS ≥ 7.1.
- Inter Tight, self-hosted via `next/font/google` (`--font-inter-tight`).

## Commands

- `npm run dev` — dev server on http://localhost:3000
- `npm run build` — static export to `out/` (also type-checks)
- `npm run lint` — ESLint
- `npx tsc --noEmit` — TS 7 type-check
- `node scripts/process-images.mjs` — regenerate `public/images/**/{full,thumb}/NNN.webp` from the raw photo folder (`../Bevan aiya`, not in the repo)

## Where things live

- `src/lib/site.ts` — **single source of truth** for founder, email, phone, location, socials, Web3Forms key. Never hard-code contact details elsewhere.
- `src/data/projects.ts` — categories, projects, stats, featured list, image path helpers. Project fields `year`, `client`, `scope`, `description` are optional and only render when filled. `kind: "concept" | "branding"` labels unbuilt work.
- `src/lib/image-size.ts` — reads image dimensions at build time (sharp) so galleries keep each photo's real aspect ratio.
- `src/components/` — `Nav`, `Footer`, `Reveal`, `ProjectCard`, `HeroBackground`, `ClientAwardsSlideshow`, `ContactForm`, `SriLankaMap`.
- Pages: `/`, `/projects` (filter via `?category=`), `/projects/[category]/[slug]`, `/services`, `/about`, `/contact`.

## Design rules

- **Surfaces:** frosted glass (`.glass`, `.btn-glass`) only over photography (hero, scrolled nav). Everywhere else: flat surfaces, 1px `border-border` hairlines, whitespace. No boxed cards.
- **Buttons:** `.btn` + `.btn-primary` (solid accent) / `.btn-secondary` (hairline) / `.btn-glass` (over photos). 44px tall, `scale(0.97)` on press. Labels in Title Case ("Start a Project").
- **Type:** headings `text-wrap: balance`; light negative tracking only on h1/h2 (Inter Tight is already tight). `.eyebrow` for small uppercase kickers. `tabular-nums` on numbers.
- **Motion:** custom curves `--ease-out` / `--ease-in-out`; UI transitions ≤ 300ms; animate only `transform`/`opacity`; hover effects are single and subtle. No page transitions. Respect `prefers-reduced-motion` everywhere.
- **Reveal:** `<Reveal delay={ms}>` keeps content visible in server HTML and only fades in elements that start below the fold. Never ship content at `opacity: 0` in the HTML.
- **Hero slideshow must NOT pause on hover** (explicit user decision). It pauses only when offscreen / tab hidden; reduced motion shows a still.
- Component classes live in `@layer components` in `globals.css` so Tailwind utilities can override them — keep it that way.
- Accessibility baseline: visible `:focus-visible` ring (global), skip link, `aria-current` on nav, native `<dialog>` for the lightbox, labelled icon buttons, 44px touch targets.

## Content rules

- **Never invent facts** (clients, years, scope, awards, services, team size). Draft copy must be grounded in what the studio has stated and flagged in `HANDOFF.md` for confirmation.
- Studio voice ("Beurant", "the studio", "we") for site copy; Bevan's own words appear only as an attributed quote. Avoid gendered pronouns for people in copy.
- Concept renders and branding/packaging work must carry a `kind` label so they aren't mistaken for built interiors.

## Gotchas

- Source files use **CRLF** line endings — regex edits must handle `\r?\n`.
- `useSearchParams` needs a `<Suspense>` boundary under static export (see `src/app/projects/page.tsx`; the fallback renders the unfiltered grid so the HTML is complete).
- `AGENTS.md` is regenerated by `next dev` — don't put project notes there; they go here.
- Contact form posts to Web3Forms when `NEXT_PUBLIC_WEB3FORMS_KEY` is set; otherwise it falls back to `mailto:`.
- `<html suppressHydrationWarning>` is intentional (browser extensions inject attributes); don't add it elsewhere without cause.
